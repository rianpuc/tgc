# Implementação N.03
## Como compilar

Utilizando o Makefile, utilize o comando:

```make adjlist``` para a gerar o binário do grafo com lista de adjacência.

## Como testar

É necessário ter a pasta ```testing``` no MESMO DIRETÓRIO DO BINÁRIO!
Você consegue baixar grafos completos e conexos aqui: [Google Drive](https://drive.google.com/drive/folders/1X4cFxXukYPVh34UhGptf1ZR5LBQd0jr4?usp=sharing)

Após colocar a pasta com o binário, execute o programa e siga as instruções, envie pressionando ENTER.

Você pode sair do programa a qualquer momento pressionando CTRL-C, ou digitando 0 nos prompts.
